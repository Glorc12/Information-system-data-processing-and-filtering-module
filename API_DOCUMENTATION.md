# API Документация

## Интеграция программных модулей через REST API

### Базовый URL
```
http://localhost:5000/api/v1
```

---

## Эндпоинты

### 1. Получение данных
**GET** `/api/v1/data`

Получить все данные из базы товаров.

**Пример запроса:**
```bash
curl http://localhost:5000/api/v1/data
```

**Успешный ответ (200):**
```json
{
  "status": "success",
  "count": 10,
  "data": [
    {
      "код": "1",
      "наименование": "Смартфон Samsung",
      "категория": "Электроника",
      "количество": "15",
      "цена": "25000"
    }
  ]
}
```

---

### 2. Передача данных
**POST** `/api/v1/data`

Отправить новые данные в систему. Данные сохраняются в `data/api_uploaded.csv`.

**Формат запроса:**
```json
[
  {
    "код": "101",
    "наименование": "Новый товар",
    "категория": "Категория",
    "количество": "10",
    "цена": "5000"
  }
]
```

**Пример запроса:**
```bash
curl -X POST http://localhost:5000/api/v1/data \
  -H "Content-Type: application/json" \
  -d '[{"код":"101","наименование":"Товар","категория":"Тест","количество":"5","цена":"1000"}]'
```

**Успешный ответ (201):**
```json
{
  "status": "success",
  "message": "Сохранено 1 записей",
  "saved_to": "data/api_uploaded.csv"
}
```

**Ошибка валидации (400):**
```json
{
  "status": "error",
  "message": "Отсутствуют поля: наименование, цена"
}
```

---

### 3. Фильтрация данных
**POST** `/api/v1/filter`

Фильтровать данные по различным критериям.

**Параметры фильтрации:**
| Параметр | Тип | Описание |
|----------|-----|----------|
| `категория` | string | Фильтр по категории (частичное совпадение) |
| `наименование` | string | Фильтр по названию (частичное совпадение) |
| `min_price` | number | Минимальная цена |
| `max_price` | number | Максимальная цена |

**Пример 1: Фильтр по категории**
```bash
curl -X POST http://localhost:5000/api/v1/filter \
  -H "Content-Type: application/json" \
  -d '{"категория":"Электроника"}'
```

**Пример 2: Фильтр по диапазону цены**
```bash
curl -X POST http://localhost:5000/api/v1/filter \
  -H "Content-Type: application/json" \
  -d '{"min_price":5000,"max_price":30000}'
```

**Пример 3: Комбинированный фильтр**
```bash
curl -X POST http://localhost:5000/api/v1/filter \
  -H "Content-Type: application/json" \
  -d '{"категория":"Периферия","max_price":5000}'
```

**Успешный ответ (200):**
```json
{
  "status": "success",
  "count": 3,
  "filters": {
    "категория": "Электроника"
  },
  "data": [...]
}
```

---

### 4. Статистика
**POST** `/api/v1/stats`

Получить статистику по данным (сумма, среднее, мин/макс).

**Пример запроса:**
```bash
curl -X POST http://localhost:5000/api/v1/stats \
  -H "Content-Type: application/json" \
  -d '{}'
```

**Успешный ответ (200):**
```json
{
  "status": "success",
  "stats": {
    "количество": {
      "сумма": 210,
      "среднее": 21.0,
      "минимум": 8,
      "максимум": 50,
      "записей": 10
    },
    "цена": {
      "сумма": 150000,
      "среднее": 15000.0,
      "минимум": 800,
      "максимум": 45000,
      "записей": 10
    }
  }
}
```

## Обработка ошибок

### Коды ответов
| Код | Описание |
|-----|----------|
| 200 | Успешный запрос (GET, фильтрация) |
| 201 | Данные созданы (POST) |
| 400 | Некорректный запрос (невалидные данные) |
| 404 | Ресурс не найден |
| 405 | Метод не поддерживается |
| 500 | Внутренняя ошибка сервера |

### Формат ошибки
```json
{
  "status": "error",
  "message": "Описание ошибки"
}
```

## Примеры использования с Python

```python
import requests

API_BASE = 'http://localhost:5000/api/v1'

# Получить данные
response = requests.get(f'{API_BASE}/data')
data = response.json()

# Отправить данные
new_item = [{
    "код": "999",
    "наименование": "Новый товар",
    "категория": "Тест",
    "количество": "5",
    "цена": "1000"
}]
response = requests.post(f'{API_BASE}/data', json=new_item)

# Фильтрация
filters = {"категория": "Электроника", "max_price": 30000}
response = requests.post(f'{API_BASE}/filter', json=filters)
```

## Структура данных

### Обязательные поля
| Поле | Тип | Описание |
|------|-----|----------|
| `код` | string | Уникальный код товара |
| `наименование` | string | Название товара |
| `категория` | string | Категория товара |
| `количество` | string/number | Количество на складе |
| `цена` | string/number | Цена товара в рублях |
