## 🏗️ Архитектура приложения

### Frontend (HTML/CSS/JavaScript)
- Веб-интерфейс на HTML5
- Стили CSS с адаптивным дизайном
- JavaScript для взаимодействия с пользователем
- Вызовы REST API к backend

**Вкладки:**
1. **Загрузка** - загрузка файлов или примеры данных
2. **Обработка** - фильтрация, сортировка, расчёты
3. **Результаты** - просмотр таблицы, экспорт, печать
4. **Справка** - документация и помощь

### Backend (Python + Flask)
- REST API для обработки данных
- Класс DataProcessor для логики обработки
- Поддержка сессий для каждого пользователя
- CORS для кросс-доменных запросов

**Основные маршруты API:**
- `POST /api/upload` - загрузка файла
- `POST /api/filter` - применение фильтра
- `POST /api/sort` - сортировка данных
- `POST /api/stats` - расчёт статистики
- `POST /api/export/<format>` - экспорт в CSV/JSON/TXT
- `POST /api/reset` - сброс фильтров
- `GET /api/sample/<format>` - примеры данных

## 📊 Описание алгоритмов

### Алгоритм фильтрации
```
1. Сохранить оригинальные данные
2. Очистить текущее множество данных
3. Для каждой записи в оригинальных данных:
   a. Получить значение поля
   b. Если оператор == 'contains':
      - Сравнить строку (case-insensitive)
   c. Если оператор == 'range':
      - Преобразовать в число
      - Проверить диапазон [min, max]
   d. Если совпадает - добавить в результат
4. Вернуть отфильтрованные данные
```

### Алгоритм сортировки
```
1. Получить текущие данные
2. Для каждой записи:
   a. Получить значение поля сортировки
   b. Попытаться преобразовать в число
   c. Если число - использовать числовую сортировку
   d. Если текст - использовать текстовую сортировку (case-insensitive)
3. Применить сортировку (возрастание/убывание)
4. Вернуть отсортированные данные
```

### Алгоритм расчёта статистики
```
1. Получить текущие данные
2. Для каждого числового поля:
   a. Извлечь все значения (с обработкой ошибок)
   b. Рассчитать:
      - Сумма = SUM(значения)
      - Среднее = SUM / COUNT
      - Минимум = MIN(значения)
      - Максимум = MAX(значения)
      - Количество = COUNT
   c. Вернуть результаты
```

## 🐛 Обработка ошибок

| Ошибка | Причина | Решение |
|--------|---------|---------|
| "Файл не выбран" | Попытка загрузить без файла | Выберите файл перед загрузкой |
| "Неподдерживаемый формат" | Расширение файла не CSV/JSON/TXT | Проверьте расширение файла |
| "Отсутствуют обязательные поля" | В файле нет всех 5 полей | Убедитесь в структуре данных |
| "Некорректный JSON" | JSON не валидный | Проверьте синтаксис JSON |
| "Нет данных для отображения" | Все записи удалены фильтром | Очистите фильтры |
| "Сессия не найдена" | Устарела сессия пользователя | Загрузите данные заново |

## 📖 Документация кода

### Класс DataProcessor

**Методы:**

```python
load_csv(content)           # Загрузка CSV
load_json(content)          # Загрузка JSON
load_txt(content)           # Загрузка TXT
filter_data(field, value, operator)  # Фильтрация
sort_data(field, order)     # Сортировка
calculate_stats(field)      # Расчёт статистики
export_csv()                # Экспорт в CSV
export_json()               # Экспорт в JSON
export_txt()                # Экспорт в TXT
get_data()                  # Получить текущие данные
get_original_data()         # Получить оригинальные данные
clear()                     # Очистить данные
```
