Информация о формате данных

Требуемые поля: код, наименование, категория, количество, цена

Приложение автоматически определяет формат файла по расширению и обрабатывает данные.

Пример CSV:

код,наименование,категория,количество,цена
001,Товар А,Электроника,50,5000
002,Товар Б,Одежда,100,1500

Пример JSON:

[
  {"код":"001","наименование":"Товар А","категория":"Электроника","количество":"50","цена":"5000"},
  {"код":"002","наименование":"Товар Б","категория":"Одежда","количество":"100","цена":"1500"}
]

Архитектура приложения

Frontend: HTML5 + CSS + JavaScript (веб-интерфейс)

Backend: Python + Flask (обработка данных)

Приложение использует клиент-серверную архитектуру с REST API для связи между frontend и backend.

Функциональные возможности

  • Загрузка данных: Поддержка форматов CSV, JSON, TXT
  • Фильтрация: По одному или нескольким критериям (категория, диапазон цены/количества, текст)
  • Сортировка: По выбранному полю в порядке возрастания или убывания
  • Расчёты: Сумма, количество, среднее значение, минимум, максимум для числовых полей
  • Сохранение: Экспорт результатов в CSV, JSON, TXT форматы

Обрабатываемые поля

Поле Описание Тип
код Уникальный идентификатор товара Текст
наименование Название товара Текст
категория Классификация товара Текст
количество Количество в наличии Число
цена Цена товара Число

Обработка ошибок

  • Ошибки чтения файла (неправильный формат, повреждённый файл)
  • Некорректный формат данных (отсутствие ожидаемых полей)
  • Отсутствие обязательных полей
  • Некорректные значения в числовых полях

API Endpoints

  • POST /api/upload - Загрузка файла
  • POST /api/filter - Применение фильтра
  • POST /api/sort - Сортировка данных
  • POST /api/stats - Расчёт статистики
  • POST /api/export/<format> - Экспорт данных
  • POST /api/reset - Сброс фильтров
  • GET /api/sample/<format> - Получить примеры данных

Установка и запуск

Требования:

  • Python 3.7+
  • Flask
  • Flask-CORS
  • pandas (опционально)

Установка зависимостей:

pip install flask flask-cors pandas

Запуск приложения:

python app.py

Приложение будет доступно по адресу: http://localhost:5000
